# 参考与实现边界

此 Skill 的规则与本地数据工具为本次独立编写，借鉴下列公开项目的工作流思想，不附带或复制其脚本、模板、个人资料。未安装这些项目，不以它们作为运行前置依赖。

- https://github.com/zhansan379/boss-crawler-skill ：简历驱动搜索、公司定向采集、分阶段匹配和投递材料预览。
- https://github.com/Hisn00w/ASu-skills ：要求与证据矩阵、申请表映射、填写回读、投递进度。
- https://github.com/sharzoy/auto-job-apply ：硬门槛优先、分级建议、逐岗投递包。
- https://github.com/qingcheng66/job-application-pipeline ：官网规则核验、岗位确认和回执闭环。未采用作者个人事实、固定届别、浏览器依赖或固定排版规则。
- https://github.com/loks666/get_jobs ：多招聘平台覆盖的需求参考，不集成其自动发送程序。

目前可直接使用：通用网络搜索与宿主浏览器驱动的按需搜岗/核验/填表工作流；本地JSON去重与历史维护脚本。
尚未实测：各招聘网站当前登录、动态列表、附件上传、表单填写和真实提交。每站首次运行记录验证范围，不宣称全站全量适配。
不是后台服务：没有自动注册调度器、申请平台账号、配置推送或额外模型API。若用户希望无人值守采集或长期提醒，另行实现并验证站点适配与调度；普通对话结束不会继续轮询。
