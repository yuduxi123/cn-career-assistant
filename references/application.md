# 网申执行

使用宿主提供的浏览器工具，先读取其文档。不要假设安装了某个第三方 WebBridge、DrissionPage 或 ego-browser。没有浏览器能力时交付材料和手动填写清单，不能声称已填写。

## 准备

- 确认公司、具体岗位、申请链接、招聘项目及用户要求的操作范围。
- 核验当前岗位仍开放、名额/志愿规则以及是否已申请。不把其他公司规则当作此公司规则。
- 使用用户提供并确认的简历。字段来源注明简历、用户明确补充、官方表单。缺失期望薪资、到岗日期、工作许可、调剂意愿时询问，不替用户猜。
- 登录、验证码与MFA交给用户。不读取浏览器密码库、不导出会话给第三方。

## 填写和提交

先展示关键资料及附件；已有明确且覆盖此岗位的授权直接执行，不为每个普通字段反复确认。上传简历会把文件发送给招聘方，应包含在已获授权的范围内。

从真实页面快照定位字段，填后回读；检查教育起止年月、毕业年月、实习周期、项目个人职责、邮箱电话、附件版本和字数限制。下拉框不能只输入文字就判成功。用户已填资料出现冲突时先核对。

最终提交前给出岗位、志愿/名额影响、简历版本、未完成项目及重要声明摘要。用户只要求填写时停在提交前；用户已经明确要求提交当前申请时，无未解决关键问题即可提交，不再机械重复问许可。

提交后读取可见回执或申请中心状态；保留申请编号、状态和时间。超时、点击无响应或页面错误属于结果不确定，先核验申请中心，不能盲目重试产生重复申请。不自动发HR消息、接受面试时间或签署承诺。

可同时准备多个岗位材料，但按具体岗位独立核验和登记。修改岗位名称或公司后重新核验资料范围，不能把“一键投递”扩展成无限制跨站群发。
